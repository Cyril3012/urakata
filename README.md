H2 Local Database Configuration
This project uses a file-based H2 database for local development. Below are the details and configuration steps:

**📁 Local Database Files**
These files are created and maintained by H2:

urakataDb.mv.db — Main database file
urakataDb.lock.db — Lock file to prevent concurrent write access
urakataDb.trace.db — Optional trace file for debugging

**Accessing the H2 Console**
Once the application is running:

Go to: http://localhost:8080/h2-console
